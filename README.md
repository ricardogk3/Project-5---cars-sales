# Project-5---cars-sales

Para rodar local use: streamlit run app.py

Leia o requirement para ver dados bibliotecas que deve ter instalado para conseguir rodar.

O arquivo serve para o inicio de conhecimento da ferramentas de trabalho. Usamos o Visual Studio Code para desenvolver esse aplicativo junto com o Steamlit. Ele realiza o filtro de uma tábela de dados de carros americanos. Podendo selecionar o preço, o tipo de câmbio e o tipo de combustível. Támbem foi feito dois checklist para poder mostrar um histograma de milhas por quantidade ou um gráfico de preço por quilometragem.
